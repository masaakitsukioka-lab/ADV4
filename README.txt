消えたスケッチ 試作版 v0.14.0
サイカチADV v0.13.1を基に、Notionの「消えたスケッチ」を実装。
原稿確認日時：2026年10月10日。ページ最終更新：同日20:12（日本時間）。
原稿：https://app.notion.com/p/3f441826315c80c3adf3e8ff24a71e02

遊び方
フォルダを丸ごと保存し、index.htmlをブラウザで開いてください。
別添のsaikachi_sketch_v0140.htmlは画像とプログラムをすべて含んだ単体版です。
単体版だけでも遊べます。Google DriveのHTMLプレビューでは実行できません。

今回の実装
・黒背景のハルキのモノローグ、タイトル、導入会話。
・美術準備室の窓／机／作品棚／ドア／床、旧校舎廊下の扉／掲示板。
・作品棚→配置図→当番表→オカボーのスケッチブックの4段階の調査。
・ナカコとオカボーの2冊の持ち物。メニュー→もちもの→品名→しらべる。
・5問の推理。最後はA／B／Cの3項目を選んで文章を完成させます。
・正解後の会話、真相説明、エンディング。
・調査メモは入手した情報だけを表示します。
・推理中に調査へ戻った場合、メニューから第1問より再挑戦できます。
・クリア後にメニューからエンディングを読み返せます。

原稿の扱い
台詞と真相を維持し、長い台詞の分割と句読点を最小限調整しています。
持ち物操作の案内、調査メモ、再調査時の短い会話、誤答ヒントを補っています。
背景2点・人物8点・コマンド画像2点はv0.13.1をそのまま使用しています。
背景は従来の美術教室の画像を、美術準備室として使用しています。
新しい人物・スケッチ画像は生成していません。
元のGoogle DriveフォルダとNotion原稿は変更していません。

セーブ
手動3枠、途中から、JSON書き出し・取り込みは既存機能を継承。
シナリオ識別子をmissing-sketch-notion-20261010に変更し、旧試作のセーブと分離。
旧版のセーブを消しません。旧版のJSONは今回の試作では読み込めません。
保存は会話と推理を終えた探索中に行ってください。
会話や推理の途中位置は保存せず、途中から後は探索状態へ戻ります。
別ブラウザ・端末への移行には「セーブの持ち運び」を使います。

編集するファイル
data/scenario.js：実行用の台詞・条件・持ち物・推理・結末。
data/scenario.json：同内容の参照用。編集時は両方を合わせてください。
data/story-ui.js：導入画面・持ち物・メモ・推理問題の画面処理。
data/events.js：既存のイベント管理（変更なし）。
data/saves.js：既存の保存処理（変更なし）。
index.html：既存画面に調査箇所と必要な表示調整を追加。
assets/：引き継いだ画像素材。
単体HTMLは編集用ファイルと自動同期しません。
