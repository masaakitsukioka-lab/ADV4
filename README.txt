今回の実装
・黒背景のハルキのモノローグ、タイトル、導入会話。
・美術準備室の窓／机／作品棚／ドア／床、旧校舎廊下の扉／掲示板。
・作品棚→配置図→当番表→オカボーのスケッチブックの4段階の調査。
・ナカコとオカボーの2冊の持ち物。メニュー→もちもの→品名→しらべる。
・5問の推理。最後はA／B／Cの3項目を選んで文章を完成させます。
・正解後の会話、真相説明、エンディング。
・調査メモは入手した情報だけを表示します。
・推理開始後は調査画面へ戻れません。問題1〜5を進めて結末へ到達します。
・クリア後はタイトルへ戻れます。

コマンド選択方式（2026-10-11）
画面上の調査対象を直接選択する方式から、重なるコマンドウィンドウへ変更。
・聞く：その場の人物に話しかけます。今回のシナリオは「ここには誰もいない」。
・調べる：場所ごとの窓・机・作品棚・ドア・床・扉・掲示板を選びます。
  机や掲示板を調べると配置図・当番表を追加。入手したスケッチブックは発見場所の準備室だけで選べます。
・探す：判明した人物名を追加。ナカコ・オカボー・犯人を対象に探します。
  今回は人物との遭遇イベントはありません。手がかりがない段階で犯人名を明かしません。
・会話：押すと直接表示。事件に関する内容を優先してランダムに選びます。
  同じ会話の連続を避けます。場面と手がかりに合う会話12種類を用意。
・移動はコマンドから場所を選択。左上に現在地、右上にメニューを表示。
・推理中は両端の人物と下部メッセージを常時表示。中央の問題枠と重ならない配置。
・導入は一文字ずつ表示。文末の点滅▼／クリックで送り、最後のクリックでディゾルブして開始。コマンドの見出しはDETECTIVE COMMAND。
発見状況はセーブに保存。既存v0.14.0の記録も読み込めます。
会話本文はdata/scenario.jsとdata/scenario.json、操作はdata/commands.jsです。

演出・文章回答の改訂（2026-10-11）
・表示順：メッセージ、人物、場所／メニュー、背景。人物は下端から高さ約4/6。
・場所とメニューは画面上部約1/6。場所名は文字を含む生成PNG。
・人物名は新聞の切り貼りを模した生成PNG。人物はメッセージ枠より0.2秒遅れて両端から入ります。
・メッセージは最大3行。長文はページを分け、枠内でスクロールしません。
・調べる一覧は項目数に応じて文字と行間を調整し、スクロールしません。
・推理移行：サイジの答え合わせの台詞→場所／メニューが退場→灰色の扉が閉じる→
  一度フラッシュ→「推理開始！」が現れて消える→問題枠が出現。
・推理枠は応答中も保持。探索に戻るボタン／Escapeでの退出は廃止。
・最後の問題はABC枠を選び、ランダム配置の12語から選択。使用した語は灰色で選択不可。
  枠を選び直して別の語へ変更できます。正解を確定するとエンディングへ進みます。
